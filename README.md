# HolyWorld Key Snatcher — диагностика NPC (Fabric 1.21.11)

## Эта версия только диагностическая
- Автоматические клики/взаимодействия отключены.
- Наведи прицел на Капитана или любую другую сущность.
- В чат один раз выводятся технический ID типа, Java-класс, обычное/отображаемое/пользовательское имя и предметы в руках (если сущность поддерживает экипировку).
- Если имя или экипировка меняются, пока прицел остаётся на сущности, выводится обновлённая строка.
- Когда прицел уходит с сущности, диагностическое отслеживание сбрасывается.

## Сборка
Нужен JDK 21. В корне проекта:
```bat
call "C:\Gradle\gradle-9.8.2\bin\gradle.bat" build
```
JAR появится в `build\libs\`.

## Что прислать
Скопируй из игрового чата строку, начинающуюся с `[KeySnatcher DEBUG]`, когда прицел наведён на Капитана. Если при наведении ничего не выводится, сообщи об этом.
